# dotfiles

Личные конфиги, управляемые через [GNU Stow](https://www.gnu.org/software/stow/). Поддерживаются **Arch Linux** и **Ubuntu**.

## Что внутри

Конфиги для: Hyprland, Waybar, Wofi, Foot, Ghostty, Neovim, Zsh (+ Starship, Zoxide, FZF) и др.

## Установка

```bash
./init.sh
```

Определяет ОС, устанавливает пакеты, назначает Zsh оболочкой по умолчанию и линкует конфиги в `$HOME`.

Только перелинковать конфиги (без установки пакетов):

```bash
bash _scripts/stow.sh
```

## Структура

Каждая директория верхнего уровня — stow-пакет, содержимое которого зеркалирует путь относительно `$HOME`. Скрипты установки лежат в `_scripts/`.
